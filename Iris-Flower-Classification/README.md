
# 🌸 Iris Flower Classification

## CODSOFT Data Science Internship - Task 2

### 📌 Project Overview
This project classifies Iris flowers into three species using Machine Learning algorithms.

### 🌼 Species
- Iris-setosa
- Iris-versicolor
- Iris-virginica

### 📊 Features
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

### 🤖 Machine Learning Models
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier
